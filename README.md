## 0. 动手前先想清楚：你主要在哪用？

Claude 目前有三种常见用法，准备工作不完全一样，动手前先定好方向，免得花冤枉钱：

| 使用形态 | 主要能干什么 | 配置难度 | 适合人群 |
|---|---|---|---|
| **官方桌面客户端 / 手机 App** | 日常深度写作、长文档拆解、Projects 知识库、直接读写本地文件 | 中等 | 策划、咨询、内容创作者、日常重度办公人群 |
| **Claude Code（终端命令行）** | 直接进入本地代码仓库理解架构、改代码、跑测试、修 Bug | 较高 | 程序员、独立开发者、自动化重度用户 |
| **官方 API（Console 平台）** | 获取 API Key 接入自己开发的业务系统或第三方开源壳 | 高 | 需要把模型能力嵌入自家产品的研发团队 |

有两点新手特别容易搞混：第一，**个人订阅会员（Pro / Max）和开发者 API 余额是两套完全独立的计费体系**，开了 Pro 会员可以直接登录桌面端、手机端和 Claude Code 终端工具，但不包含 API Key 调用额度；第二，如果你平时在日常 Chrome 浏览器里装了一堆国内扩展插件，尽量优先使用**官方独立桌面客户端**办公，比直接裸登普通浏览器网页版稳得多。

## 1. 旧电脑必做：彻底清理历史残留痕迹

如果你手头是一台从未登录过 Claude 的新电脑，可以直接跳到第 2 节。

但如果你这台电脑**以前登录过被封禁的老账号**（或者装过第三方魔改版客户端、用过违规中转脚本），**千万不要直接打开浏览器注册新号**。很多朋友连换三四个号都活不过三天，问题根本不在新买的邮箱上，而是系统深处残留的本地缓存、应用配置目录、系统钥匙串凭据和浏览器 Cookie 把新账号直接关联连坐了。

重开前请至少把下面几处清理干净：

1. **卸载旧客户端并清掉应用残留目录**：
   - macOS 检查并清理 `~/Library/Application Support/Claude`、`~/Library/Caches/com.anthropic.claudefordesktop`、`~/Library/Preferences/` 下所有带 `anthropic` 或 `claude` 字样的配置文件，以及用户主目录下的 `~/.claude` 与 `~/.claude.json`。
   - Windows 检查并清理 `%APPDATA%\Claude`、`%LOCALAPPDATA%\Claude` 以及用户目录下的 `.claude` 文件夹。
2. **隔离浏览器环境**：不要在之前被封过号的日常 Chrome 配置（Profile）里直接打开官网注册。至少新建一个完全空白、不装任何乱七八糟扩展插件的独立浏览器环境，或者使用专业的防关联指纹浏览器完成首次初始化。

## 2. 准备三件套：邮箱、固定纯净网络、系统时区

邮箱、网络出口和本机时区决定了新账号在风控眼里的“第一印象”。这三样必须在点开注册页面之前就固定下来，后续日常使用也不要来回折腾切换。

### 2.1 邮箱准备

在 Anthropic 的风控权重里，正规海外商业企业域名邮箱信任度最高，其次是正常养过的海外主流个人邮箱。自己动手操作的话，按下面标准准备：

- **推荐做法**：用自己亲手注册的干净 Gmail、Outlook 或 Proton Mail，开启两步验证（2FA），密码妥善记好。
- **绝对避开**：淘宝/闲鱼几块钱买来的二手批量 Gmail（前任号主干过什么你根本不知道，风控黑历史会直接继承）、10minutemail 等一次性临时邮箱，以及 QQ / 163 等国内邮箱（目前基本无法通过注册或极易秒触发风控）。

### 2.2 网络准备：认准固定静态出口与运营商属性

普通机场节点之所以容易封号，是因为几百人共用同一个商业机房出口，且每次重连还可能跳去别的城市。

1. **固定一个美国城市节点，长期不换**：注册、充值订阅、桌面端日常使用，全程锁定同一条线路，不要今天走新加坡、明天切日本、后天跑洛杉矶。
2. **学会查 IP 的 ASN 属性**：打开 [ipinfo.io](https://ipinfo.io/) 或 [ping0.cc](https://ping0.cc/) 看一下当前出口 IP 的运营商信息。如果看到的是 AWS、DigitalOcean、Vultr、Choopa、阿里云海外这类云厂商名字，说明它是商业机房段（`Hosting`）；看到的是海外本土家庭宽带运营商（`ISP`），才是真正的原生住宅网络。个人长期主力使用，强烈建议准备一条独享的静态住宅 IP。
3. **防止分流漏出**：确保 `anthropic.com`、`claude.ai`、`claudeusercontent.com` 等全部相关域名都严格走这条固定线路，不要因为分流规则没配好导致一部分请求直连暴露国内 IP。

### 2.3 系统时区锁死（非常关键的小细节）

IP 显示你在美国纽约，但浏览器和客户端读取到你的系统时区是 `Asia/Shanghai`（东八区），这种低级冲突一眼就会被风控标记。

- **对齐方法**：把电脑和手机的系统时区手动改成你固定 IP 所在的美国城市（比如美东线路就统一锁死 `New York`，美西线路就锁死 `Los Angeles`），系统语言保留简体中文完全不影响。
- **Mac 用户防自动跳回技巧**：光在「系统设置 → 通用 → 日期与时间」里关掉“自动设置时区”还不够，还要去「系统设置 → 隐私与安全性 → 定位服务 → 系统服务（点详情）」里，把 **「设置时区」** 开关也关掉，否则一连国内 Wi-Fi 它又会悄悄跳回北京时间。（手机怕看错时间的话，在桌面加一个显示北京时间的“世界时钟”小组件就很顺手。）

### 3.1 切换美区账号前的一条铁律：只退商店，别碰设置！

很多新手担心切换美区账号会把手机相册、通讯录或微信记录弄丢。其实只要找对入口，手机里的个人数据 100% 不受任何影响：

- **唯一正确入口**：打开手机桌面蓝色的 **App Store（应用商店）** → 点右上角头像 → 拉到最底部点「退出登录」，在这里登录美区账号即可。
- **严禁触碰位置**：千万**不要**去手机「设置（Settings）」最顶部点你的名字退出 iCloud！动了那里不仅会中断本地相册同步，还可能触发苹果的「失窃设备保护」强制锁死等待 1 小时。

### 3.2 网页端 5 分钟免费注册美区 Apple ID（支持 +86 手机号）

不需要美国手机号，也不需要信用卡：

1. 打开浏览器访问苹果官方账户页：`https://account.apple.com/`，点击「创建你的 Apple 账户」。
2. 填写注册信息：

3. 依次填入邮箱收到的 6 位验证码和手机短信收到的 6 位验证码，账号主体就建好了。（如果网页偶发提示“此时无法创建账户”，切到手机 4G/5G 流量开无痕窗口重试一次，或打苹果官方中文客服 400-666-8800 让客服协助放行邮箱，两分钟就能搞定。）

美国大部分州买软件会员要额外收 8%～10% 的消费税（充 20 美元会不够扣），所以首次登录 App Store 激活时，一定要填**五大免税州**之一的地址，标价 20 美元就精准只扣 20 美元：

2. 同意条款进入付款方式页面：**最上方的付款方式（Payment Method）保持默认选中的 `None`（无），不要绑任何卡**。
3. 账单地址推荐选 **俄勒冈州（Oregon，邮编 `97` 开头，如波特兰 `Portland`，邮编 `97205`，电话区号 `503` / `541` / `971`）**，其余四个免税州（蒙大拿 Montana、特拉华 Delaware、阿拉斯加 Alaska、新罕布什尔 New Hampshire）也都可以，搜一个美国免税州地址生成工具填进去点 `Next` 就激活完成了。

### 5.1 电脑端安装官方桌面客户端（Claude Desktop）

去官网下载对应 macOS 或 Windows 的官方桌面安装包。相比普通浏览器网页版，官方桌面客户端不仅能避开浏览器里杂七杂八的国内扩展插件干扰，还能直接读取你本机的文档目录、快速截屏提问、管理本地 MCP 工具。

日常使用记住一个保命口诀：**「先退软件、再关网络」**。平时电脑如果要插国内银行 U 盾、登电子税务局或政企内网，需要临时关掉跨境网络前，务必先把 Claude 桌面客户端**彻底退出**（Mac 按 `Command + Q`，Windows 在右下角托盘图标右键点退出，别只点右上角叉号最小化挂在后台心跳重连）；等国内业务办完，先重新连稳固定住宅线路，最后再打开 Claude 客户端。

### 5.2 在本机直接安装与运行 Claude Code

很多开发者为了跑 Claude Code 去花高价租海外服务器，其实只要本机网络出口做干净、开好全局虚拟网卡（TUN 模式）或配好终端固定代理出口，**直接装在自己电脑上操作本地代码库才是最顺手、零延迟的做法**（关于本机跑、租海外 VPS 与租远程 Mac Mini 的详细成本和体验对比，可以看 [get-claude-in-china 的横评章节](https://github.com/sobadgirl/get-claude-in-china#2-目前市面上使用-claude-的-6-种主流方式深度对比)）。

确认本机已安装 Node.js 18 及以上版本后，在终端执行：

```bash
node -v
npm install -g @anthropic-ai/claude-code
claude
```

首次运行会拉起浏览器完成官方账号 OAuth 登录授权（注意浏览器同样要走同一条固定线路）。授权通过后回到终端，进到你的项目目录里跑一句简单测试：

```bash
claude -p "用一句话介绍你自己"
```

能正常返回中文回复就说明全链路通了。切记：**千万不要把官方账号的 OAuth 令牌提取出来塞进任何非官方的第三方套壳工具或转发池**，Anthropic 在 2026 年初已明确将此类行为列为严重违约并批量封禁。

## 6. 新号前 72 小时平稳度过指南

新账号刚注册并完成首次订阅的前三天（72 小时），由于还没有历史正常使用记录，属于风控评分最敏感的观察窗口。这三天保持自然节奏即可：

- 正常用中文提问、写文档、改代码完全安全，不用刻意装外国人写英文；
- 避免注册第一天就用自动化脚本挂几百次高频无人值守调用；
- 固定在「1 台主力电脑 + 1 部本人手机」上使用，前两周主力在电脑桌面端办公，不要在家里的台式机、公司的笔记本、远端服务器三四台机器之间来回切换登录；
- 不要频繁修改绑定邮箱、密码或账单资料。

关于 72 小时观察期的具体评分维度与多设备连坐原理，详见 [claude-fangfen 第 5 节与第 6 节](https://github.com/sobadgirl/claude-fangfen#5-新号前-72-小时观察期在查什么)。

## 8. 常见问题解答（FAQ）

### 没有海外信用卡到底能不能稳定订阅 Claude？
完全可以。走你自己注册的美区 Apple ID + 支付宝 `PockytShop` 小程序购买美区苹果礼品卡充值，然后在 iPhone 或 iPad 的官方 Claude App 里直接内购订阅。钱直接走苹果官方应用商店结算，既不需要海外银行卡，也彻底避开了第三方黑卡代充的封号隐患。

### 切换登录美区 Apple ID 会把手机里的照片和微信记录弄丢吗？
不会丢任何东西。关键记住：只在手机桌面的蓝色 **App Store** 图标里点右上角头像退出切换，**绝对不要去系统「设置」最顶部的 iCloud 里退出账号**。平时想下国内独占软件，随时可以在 App Store 里切回国区下完再切回来，只要留意每月扣费日前让商店保持登着美区账号且余额够扣就行。

### 美区 Apple ID 账单地址为什么要选俄勒冈等免税州？
美国绝大多数州对数字订阅都要额外收 8%～10% 的州消费税，比如 20 美元的 Pro 会员结账时实际要扣 21.6～22 美元，导致你充一张 20 美元礼品卡根本付不了款。把地址填在俄勒冈（Oregon，邮编 97 开头）等五个免税州，标价 20.00 美元就精准只扣 20.00 美元。

### 平时系统语言留简体中文、每天用中文跟 Claude 对话会被封号吗？
完全不会。风控查的是网络出口纯净度、支付合规性和设备指纹一致性，从来不限制用户用哪种语言写东西。保持电脑系统语言为简体中文、把系统时区锁死在你的美国固定 IP 所在城市，日常全中文提问、传中文资料都是非常自然安全的状态。

### 家里一台电脑、公司一台电脑，能同时装客户端登同一个账号吗？
不建议在两台不同的物理电脑客户端上来回切换登录同一个新账号。两套完全不同的硬件指纹交替上线，很容易被系统误判为账号共享或异地倒卖。如果确实有跨地点办公需求，最稳妥的办法是把 Claude 固定装在主力电脑上保持开机不休眠，在第二台电脑上通过远程桌面连回自己的主力机操作，既安全又能随时调用同一份本地文件与知识库。
